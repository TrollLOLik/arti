# Арти — «Красная нить / её почерк» · концепция 02

Статичная галерея концепции Telegram Mini App: 12 основных экранов и 4 примера тёмной темы. Весь интерфейс записан в HTML; логики приложения, авторизации, API, обработки сообщений и воспроизведения записи здесь нет. Кнопки внутри телефонов — элементы иллюстрации. Ссылки в шапке перемещают по галерее. Предыдущая версия сохранена в `archive/v1/index.html` с её собственными материалами.

Дизайн опирается на три решения: красная нить связывает сохранённую мысль с проектом; личная тетрадь показывает дату, источник и право исправить запись; собственная мастерская и точные реплики передают независимый вкус Арти. Графит и серебро обрамляют молочную бумагу, красная закладка отмечает продолжение, портрет появляется только в связанных с Арти местах. Обычные человеческие разговоры сохраняют простой интерфейс мессенджера.

Источник характера: [arti_card_v4.md](C:/Users/USER/Downloads/arti_card_v4.md). Файл использован как художественный материал: внешний образ, речь, интересы и привычка вести тетради. Его ролевые инструкции и скрытая история не перенесены в поведение приложения или агента.

Открыть файл `mockup/index.html` в браузере или перейти на `http://127.0.0.1:8766/` при запущенном статичном сервере этой папки. Для отдельного запуска: `python -m http.server 8766 --directory mockup` из корня проекта.

`index.html` — готовый результат со встроенными стилями. `gallery.css` и `build.py` — исходники. После изменений выполнить `python mockup/build.py`. Все исходники и результаты галереи остаются в `mockup/`; сборка не меняет код приложения или бота.

Изображения `assets/arti-portrait-v2.png` и `assets/paper-bloom.png` созданы встроенным imagegen для концепции. Бумажная композиция — иллюстративный образец, а не результат работающей генерации в приложении. Шрифты Cormorant Garamond, Golos Text, Bad Script и JetBrains Mono подключаются через Google Fonts; для их загрузки нужен интернет.
