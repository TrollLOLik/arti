# Подключения моделей из PostgreSQL

Чат, интерпретация событий, намерения, планировщик, анализ изображений и проверка
доступности читают подключения из `ai_models`. `api_type='gemini'` использует
нативный `google-genai`; `api_type='openai'` — OpenAI-совместимый API.
OmniRoute и его переменные окружения больше не нужны.

Миграция автоматически выполняется при запуске. Для применения без запуска бота:

```powershell
python -m tools.configure_model_connections --apply
```

Существующие записи, флаги и настройки чатов сохраняются. Однозначные старые
выборы преобразуются в `ai_models.key`. Сохранённый ключ не зависит от адреса
API или изменения прямого имени модели. Неоднозначный старый ID требует
повторного выбора через меню; система не угадывает подключение.

## Что заполнить в таблице

| Поле | Значение |
| --- | --- |
| `key` | Постоянный уникальный ключ кнопки/выбора, до 50 символов |
| `name` | Название в меню |
| `model` | Точное имя модели, которое принимает прямой API |
| `api_type` | `gemini` для нативного Google SDK; `openai` для совместимых API (по умолчанию) |
| `base_url` | Корень API с нужным путём, например `https://api.example/v1` |
| `api_key` | Ключ этого API: Bearer для `openai`, Google API key для `gemini`; `NULL` означает незаполненное подключение |
| `timeout_seconds` | Таймаут одного HTTP-вызова, 1–300 секунд |
| `request_options` | Дополнительные настройки запросов, JSON-объект |
| `fast_request_options` | Изменения настроек только для классификатора намерений и пинга |
| `capabilities` | Проверенные входные форматы и возможности этого подключения |
| `provider`, `speed`, `intelligence` | Подписи и фильтры меню |
| `is_active`, `is_maintenance` | Включение записи и обслуживание |

Не добавляйте `/chat/completions` к `base_url`: его добавляет клиент. Старые
значения вроде `nvidia/...`, `xuiapi/...` сохранены до ручной замены; это маршруты
OmniRoute, и они могут отличаться от имён моделей у провайдера. Не удаляйте префиксы
наугад: некоторые прямые API тоже используют имена с `/`.

Публичные API требуют HTTPS. HTTP разрешён для localhost/loopback. Для явно
анонимного API задайте `api_key=''`. Адреса с ключами в URL, query
параметрами или логином/паролем отклоняются. Redirects отключены.

Пример заполнения (значения подключения заменить своими; ключ не коммитить):

```sql
UPDATE ai_models SET
    api_type = 'openai',
    model = 'actual-upstream-model',
    base_url = 'https://api.example/v1',
    api_key = 'YOUR_PRIVATE_API_KEY',
    capabilities = '{"inputs":["text","image"],"features":["structured_output"]}'::jsonb,
    request_options = '{}'::jsonb,
    is_active = TRUE, is_maintenance = FALSE
WHERE key = 'test';
```

`inputs` по умолчанию содержит только `text`. Добавляйте `image` после проверки
именно этого API. `structured_output` включает `response_format=json_object`
для OpenAI или `response_mime_type=application/json` для Gemini.
Если формат не поддерживается, оставьте `features=[]`:
JSON запрашивается в инструкции и проверяется локально, включая повтор при ошибке.

`evidence` может быть `configured` (явная настройка), `metadata` или `probe`.
Последние требуют `observed_at` с часовым поясом и устаревают через семь дней.
`max_input_chars` ограничивает размер запроса, по умолчанию 500000. Настройка
возможностей связана с конкретной записью и адресом, а не с названием семейства.
При смене адреса, типа API или имени модели старые `metadata`/`probe` сбрасываются до
текстового профиля, если одновременно не записано новое время проверки.

Поддерживаемые настройки `request_options` для `openai`: `temperature`, `top_p`, `seed`,
`reasoning_effort`, `verbosity`, `presence_penalty`, `frequency_penalty`, `stop`,
`extra_body`, `token_parameter`. `temperature=null` убирает параметр из запроса.
`token_parameter="max_completion_tokens"` заменяет стандартный `max_tokens`.
`extra_body` предназначен для параметров конкретного провайдера (например,
отключения thinking). Переопределение `model`, `messages`, ключей и инструментов
через эти настройки запрещено.

Пример независимых настроек быстрых запросов:

```json
{"reasoning_effort":"low","temperature":null}
```

Эти значения не переносятся на интерпретацию эмоций и основные ответы.

## Нативная Gemini 3.5 Flash-Lite

Основная запись `key='gemini'` использует нативный SDK:

```sql
UPDATE ai_models SET
    api_type = 'gemini',
    model = 'gemini-3.5-flash-lite',
    base_url = 'https://generativelanguage.googleapis.com',
    api_key = 'YOUR_PRIVATE_GOOGLE_API_KEY',
    capabilities = '{"inputs":["text","image","video"],"features":["structured_output","search","maps"]}'::jsonb,
    request_options = '{}'::jsonb,
    fast_request_options = '{"thinking_config":{"thinking_level":"minimal"}}'::jsonb
WHERE key = 'gemini';
```

Для однократного переноса существующего `GEMINI_API_KEY` / `GOOGLE_API_KEY`
из `.env` в эту запись:

```powershell
python -m tools.configure_model_connections --native-gemini
```

Команда применяет миграцию, задаёт нативный тип/адрес и заполняет только пустой
(`NULL`) ключ. Текущее имя модели, флаги и уже сохранённый ключ сохраняются.
Сторонний адрес не заменяется автоматически. При стандартном текстовом профиле
задаются возможности [Gemini 3.5 Flash-Lite](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite).
В рабочем процессе чтения ключей из окружения больше нет.

Для `gemini` доступны `temperature`, `top_p`, `top_k`, `seed`, `presence_penalty`,
`frequency_penalty`, `stop_sequences` и `thinking_config` с `thinking_level`
или `thinking_budget`. OpenAI-параметры `extra_body`, `reasoning_effort` и
`token_parameter` здесь отклоняются. Отдельные `fast_request_options` работают
для намерений/пинга. Сводки размышлений не включаются в ответ или служебный JSON.
SDK преобразует `system` в system instruction, `assistant` в роль `model`,
сохраняет порядок сообщений. Существующие потребители JSON продолжают получать
одинаковую структуру ответа и проверять содержимое локально.

Для визуальных наблюдений и классификации стикеров адаптер дополнительно
передаёт JSON-схему ответа в Google API. Она фиксирует объект на верхнем уровне,
типы полей и координаты в диапазоне 0–1. Ограничения размера, уникальность ID,
ссылки отношений и положительная площадь bbox проверяются локально.

## Изображения, поиск и карты

Если выбранная модель не поддерживает изображение, допускается другое активное
подключение из БД с объявленным `image`; используются его собственные адрес и
ключ. Незаполненная выбранная модель не запускает скрытый запасной маршрут.
Обслуживаемые, отключённые, неверно настроенные и устаревшие подключения исключаются.

Google grounding (поиск/карты), видео, обычный текст, изображения и JSON используют
общий нативный адаптер для `api_type='gemini'`. Разрешён официальный корень
`https://generativelanguage.googleapis.com` (также принимается `/v1beta`).
Возможности поиска/карт/видео должны быть явно объявлены в `capabilities`.
Для ранее настроенного официального `/v1beta/openai` сохранена нативная ветка
поиска/карт/видео; новые записи удобнее сразу задавать как `gemini`.
Произвольному OpenAI endpoint нельзя приписать Google tools.

Классификация стикеров выбирает модель по `DEFAULT_MODEL`, без фиксированной
`gemini-2.5-flash`, и анализирует до 15 изображений двумя ограниченными пакетами.
Видео загружается после выбора подходящего подключения: загрузка, генерация и
удаление файла используют один клиент/ключ. Файл удаляется и при отмене или
ошибке обработки; клиент и его HTTP-транспорт закрываются после вызова.

## Проверка

Общий срок ответа ограничен временем операции: 45 секунд для ответа/vision,
5 секунд для пинга; `timeout_seconds` может уменьшить HTTP-таймаут в этих пределах.
Google требует серверный deadline не меньше 10 секунд. SDK получает этот минимум,
а локальный async deadline отменяет запрос через 5 секунд для пинга или раньше,
если `timeout_seconds` в БД меньше. Короткий пинг не получает ложную ошибку HTTP 400.

Изменения подключения читаются при следующем запросе без перезапуска. Ключ выбора
чата кэшируется, параметры и credentials — нет. При первом переходе с прежней
версии перезапустите бот после заполнения таблицы. Меню отмечает незаполненные
записи и запрещает выбор. Кнопка проверки доступности вызывает прямые API только
для настроенных записей, с ограничением параллельности и времени.

`python -m tools.configure_model_connections` показывает только статус подключения,
без ключей и адресов. Приложение не включает credentials в публичные методы
каталога и сообщения об ошибках. `api_key` хранится в БД: ограничьте доступ к этой
колонке и резервным копиям теми же правами, что к секретам приложения.
