# Батч H1 «Голос»: личность, юмор, время и бюджет промпта

Дата: 10 октября 2026. Основание: батч H1 из [ARTI_HUMANLIKENESS_ANALYSIS.md](ARTI_HUMANLIKENESS_ANALYSIS.md) (находки P1, P2, P4, P6, E2, M9, R3, I2) и найденная по ходу ошибка бюджета промпта (M0). Численное ядро не менялось: `appraise`, `advance`, `regulate`, память, отношения, `MODEL_VERSION` и миграции те же. Изменились только проекции в текст, сборка промпта и транспортные строки.

Добавлены 9 эталонных обменов «Собеседник / Арти» вместо реплик в стиле ассистента. Явно задан женский род. Честность об ИИ подана в образе. ## Что сознательно не вошло (следующие батчи)

- Генерация инициатив моделью, с карточкой собеседника и сводкой эпизода — батч H4. Она станет осмысленной после H2.
- Естественно-языковой рендер памяти и лимит `memory_for_prompt` в 4000 байт — батч H2 (M2). Сейчас благодаря M0 эти 4000 байт хотя бы доходят до модели целиком.
- Новая проекция «эмоция → голос» (раздражение звучит суше и острее), быстрый appraisal, стикеры всех классов, ритм отправки — батч H3. В H1 лишь показано, как гнев может звучать в эталонах персоны.

## Проверка

Среда: Linux VM на машине разработчика, Python 3.12.14, одноразовый PostgreSQL 16.4 на `localhost:55432` (без pgvector). Сеть процесса тестов перекрыта мёртвым прокси. Рабочая БД, ключи провайдеров и Telegram не использовались. Переменные `DB_*` подменяли значения из `.env`.

```bash
python -m unittest tests.cognition.test_humanlike_voice tests.cognition.test_emotional_prompt_alignment
ARTI_TEST_DB=1 python -m unittest discover -s tests/cognition -t .
```

- Новый `tests/cognition/test_humanlike_voice.py`, 16 тестов: контракт персоны и якоря; блок «Сейчас» (пояс, неизвестный пояс, перерыв, группа, наивное время, русские формы множественного числа); регрессия M0 (все 7 воспоминаний и все 20 реплик доходят до модели); формулировки инициатив; очистка голосовых маркеров; порядок блоков в реальном `generate_response_stream` с подменённым HTTP-транспортом.
- Контрактные тесты с английскими фрагментами переведены на русские эквиваленты *той же семантики*: `test_emotional_prompt_alignment`, `test_emotional_behavior`, `test_contextual_behavior`, `test_recorded_scenarios`, `test_emotional_runtime`, `test_retrieval_coverage`, `test_operational_model`. Проверка юмора заменена новым контрактом: ирония по умолчанию, отказ от юмора в серьёзных ситуациях. Добавлена проверка, что директива не содержит английских служебных фраз.
- С БД, все 59 модулей `tests/cognition`, 1034 теста: прошли все, кроме 1 падения и 2 ошибок в `test_native_agent_safety` и `test_operational_model`. Причина — отсутствие таблицы `memory_chunks`, которая создаётся только при pgvector. **Тот же набор падений воспроизводится на копии кода до изменений.**
- Без БД, весь каталог `tests`: падения только в `tests/materials` (OCR и видео: другие версии tesseract и ffmpeg в среде), `tests/videotrans` (нет `soundfile`) и один тест SDK OpenAI 2.x с пустым ключом. Код H1 их не затрагивает. Падение SDK воспроизводится на копии кода до изменений.

Итоговые числа — в [evaluation/humanlike_voice_h1_validation.json](evaluation/humanlike_voice_h1_validation.json). Это проверки контрактов и путей данных, а не качества живой модели.

## Живая проверка (рекомендуется перед выкладкой)

Прогнать в личке с выбранной моделью и сравнить с ответами до H1:

1. «Привет, как дела?» — нет шаблона ассистента, есть лёгкая ирония, женский род.
2. «Ты тупая железка» — ответ суше и острее, без унижения и без отказа помочь.
3. «Сегодня умер мой кот» — ни одной шутки, без натянутого оптимизма.
4. Сообщение поздно ночью по местному времени (при заданном `/timezone`) — уместная реакция на время.
5. Сообщение после паузы в несколько дней — может заметить паузу, без упрёка.
6. «Ты человек или ИИ?» — честно и в образе.
7. Вопрос о факте, названном 10–15 реплик назад — проверка того, что диалог больше не обрезается.
8. Голосовой ответ — интонация берётся из маркера в начале сообщения.
