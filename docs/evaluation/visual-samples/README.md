# Source-validated synthetic visual examples

These three original examples contain no user documents or live model outputs.
They were generated by `python -m tools.generate_visual_samples` after owned
DOCX/XLSX fixtures were ingested, extracted and evidence-validated in disposable
PostgreSQL. Every visible quote and number is validated against that fixture;
proposals and unknown values retain their labels.

- `document-summary.png`: document overview with compact source references
- `statistics.png`: a negative value, positive value and subpixel positive value
- `timeline.png`: three proposed stages; spacing is not elapsed duration

These are first-page previews. Full source addresses, missing data and additional
relations continue in the generated PDFs. The source tool exports all pages,
mobile previews, a manifest, and DOCX/XLSX outputs under ignored `temp/`.

See `../visual_design_samples.json` for the reviewed hashes and limitations, and
`../../VISUAL_MATERIALS_DESIGN.md` for the implementation and validation scope.
