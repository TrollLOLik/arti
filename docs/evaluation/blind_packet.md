## neutral

Контекст: Объясни, чем tuple отличается от list.

**A**
`tuple` — неизменяемая последовательность, поэтому её элементы нельзя добавить, удалить или заменить. `list` — изменяемая: элементы можно менять, добавлять и удалять.

Пример:
- `t = (1, 2, 3)`
- `l = [1, 2, 3]`

Оба хранят упорядоченные элементы и поддерживают индексацию. `tuple` часто используют для фиксированных данных, а `list` — для наборов, которые могут меняться.

**B**
`list` — изменяемый упорядоченный набор: в него можно добавлять, удалять и заменять элементы.

`tuple` — неизменяемый упорядоченный набор: после создания его нельзя изменить.

Например:

```python
items = [1, 2, 3]
items.append(4)  # list можно изменить

point = (1, 2)
# point[0] = 5  # tuple менять нельзя
```

Кортежи часто используют для фиксированных значений, например координат, и как ключи словаря, если их элементы тоже неизменяемы.
