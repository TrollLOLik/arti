## Reproducible artifacts

- `tools/evaluate_retrieval_context.py` and `docs/evaluation/retrieval_context_synthetic.json`: controlled SQL ranking evidence, not learned-model accuracy.
- `tools/evaluate_encoder_probe.py --model-dir <separately-provisioned-pinned-dir> --output <report.json>` and `docs/evaluation/semantic_encoder_probe.json`: seven fixed synthetic paraphrases, top-1 and cutoff metrics reported separately. No weights are checked in or installed into the bot's default directory.
- `tools/evaluate_long_conversations.py` and `docs/evaluation/long_conversations_synthetic.json`: synthetic trajectory invariants, no raw private transcripts.
- `docs/native_organizer.md`: supported commands, natural requests, schedule and delivery semantics.
- `docs/durable_requests.md`: inherited post-enqueue durability guarantees and exclusions.

## Platform and verification boundaries

Testing uses Linux, dummy credentials, synthetic input and disposable PostgreSQL. POSIX subprocess sessions allow group termination; the Windows fallback terminates the direct child only. The `tzdata` fallback is regression-tested with an empty system timezone path. Full Windows descendant/GPU cleanup is **not verified**. Threaded SDK work cannot always be killed and must not be described as cancelled remotely.

The former document-parser resource/error-classification failures were fixed in a distinct bounded change: tiny affine calculations no longer need BLAS workspace, and a final disk-budget/SIGXFSZ check classifies the exit race. OpenCV is also capped to one native OCR thread: bounded isolated diagnostics reproduced 2 failures in 40 uncapped workers and 0 in 40 patched workers. Memory, filesystem and wall-clock sandbox limits remain unchanged.

Use `ARTI_TEST_DB=1 python -m unittest discover -s tests -t .` in an offline test environment, or the repository's aggregate runners. Do not use production history or credentials for evaluation. Final release reporting must give the actual aggregate test outcome and retain the human, platform and coverage gaps above; this plan does not mark them complete merely because code exists.
